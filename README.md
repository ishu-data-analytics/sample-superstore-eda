## Sample Superstore – Exploratory Data Analysis (EDA)

Exploratory Data Analysis of retails sales and profitability using Python, Pandas and Matplotlib.

Project Overview

This project explores retail sales and profitability using Python. The objective is to identify business insights and opportunities to improve profitability.

Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab

Dataset

The dataset contains retail order information, including product categories, regions, sales, discounts, quantities, and profits.

Analysis Performed

- Data cleaning and duplicate removal
- Missing-value checks
- Sales and profit analysis
- Category and sub-category profitability analysis
- Data visualization

Key Findings

- Total Sales: Approximately $2.30 million
- Total Profit: Approximately $286,242
- Overall Profit Margin: Approximately 12.47%
- Technology generated the highest profit among the main product categories.
- Tables, Bookcases, and Supplies had negative total profit.

Business Recommendations

- Review pricing and discounts for loss-making sub-categories.
- Investigate ways to improve Furniture profitability.
- Compare regional performance.
- Monitor profit margins alongside sales.

Conclusion

This project provided practical experience in data cleaning, exploratory data analysis, visualization, and communicating business insights using Python.
